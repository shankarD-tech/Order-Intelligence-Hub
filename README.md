# **Order Intelligence Hub**

**Order Intelligence Hub** is a **Power BI-based business intelligence project** that integrates food delivery, customer, restaurant, payment, and delivery data into interactive dashboards. It provides comprehensive insights into order performance, customer behavior, restaurant efficiency, revenue trends, and delivery operations, enabling data-driven decision-making and improved business performance.

---

## 🚀 Features

* Order and revenue analytics
* Customer behavior and demographic insights
* Restaurant performance monitoring
* Delivery partner performance analysis
* Payment method and delivery type analysis
* Cuisine and product popularity tracking
* Interactive dashboards with KPI reporting
* Dynamic filtering using slicers

---

## 🛠️ Tools & Technologies

* **Power BI**
* **Microsoft Excel**
* **Power Query**
* **DAX (Data Analysis Expressions)**
* **Data Modeling**
* **Data Visualization**

---

## 🧪 How It Works

* Collects and integrates food delivery datasets from multiple business operations.
* Cleans and transforms data using **Power Query**.
* Builds relationships and calculations using **Data Modeling** and **DAX**.
* Creates interactive dashboards for order, customer, and restaurant analytics.
* Enables real-time exploration of KPIs through slicers and dynamic visualizations.

---

## 💡 Key Insights

* Total orders, revenue, and average order value

* City-wise order distribution
